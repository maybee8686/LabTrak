# LabTrack

Приложение для учёта лабораторных работ: этапы, измерения, анализ данных, отчёты в Word и PDF.

## Запуск (Windows)
1. Установите Python 3.10+ с python.org (при установке отметьте «Add Python to PATH»
   и оставьте включённым «tcl/tk and IDLE»).
2. В папке проекта выполните:
       pip install -r requirements.txt
       python main.py
3. Проверка логики без окон: `python test_core.py`

## Сборка в .exe
    pip install pyinstaller
    pyinstaller --noconsole --onefile --name LabTrack main.py
Готовый файл появится в папке `dist`.

## Данные
База хранится в `%APPDATA%\LabTrack\labtrack.db`. Чтобы сделать резервную копию, скопируйте этот файл.

## Как пользоваться
- «Новая» — создать работу; на вкладке «Описание» задайте название, срок и величины X/Y.
- «Этапы» — чек-лист; двойной клик отмечает этап выполненным.
- «Измерения» — вводите пары X и Y или вставляйте два столбца из Excel.
- «Анализ» — среднее, погрешности, линейная аппроксимация (МНК).
- «Отчёт» — напишите вывод и экспортируйте в Word или PDF.
